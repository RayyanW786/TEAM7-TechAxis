# Security Policy

## Supported Version

Only the latest submitted project version is considered supported.

## Reporting a Vulnerability

Do not open public issues for sensitive security problems.

Instead:

1. Report the issue privately to the project maintainers or module team contact.
2. Include a clear description of the issue, affected area, and reproduction steps.
3. Allow time for the issue to be reviewed before wider disclosure.

## Scope

This policy applies to:

- authentication and authorisation issues
- database access or privilege problems
- sensitive data exposure
- checkout, discount, or order manipulation vulnerabilities
- admin privilege escalation or workflow bypasses
