# Code of Conduct

## Project Status

This project is complete and has reached its final submission state.

The expectations below remain in place for any final review, handover, clarification, or issue that may arise after submission.

## Expected Behaviour

- Communicate respectfully and professionally.
- Give constructive, relevant feedback.
- Keep discussion focused on resolving the issue at hand.
- Respect the work, time, and contributions of all Team 7 members.

## Unacceptable Behaviour

- Harassment, discrimination, or personal attacks
- Dismissive or hostile behaviour
- Sharing private or sensitive information without permission
- Deliberately disruptive or bad-faith conduct

## If An Issue Arises

If any issue arises after submission, it should be raised respectfully with the project maintainers or the appropriate module contact using the agreed communication channel.
